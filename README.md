# SHINCERTIFICATE — Водонепроницаемость бетона

Настольная программа для испытательной лаборатории **«ՇINCERTIFICATE»**.  
Автоматизированный расчёт водонепроницаемости бетона по **ГОСТ 12730.5-2018** (метод воздухопроницаемости), прибор **№3407**.

## Что делает

- Принимает время t для 6 образцов и заявленную марку W для каждого
- Рассчитывает воздухопроницаемость aᵢ, сопротивление mᵢ и фактическую W
- Сравнивает фактическую W с заявленной (соответствует / не соответствует)
- Экспортирует заполненный Excel по оригинальному армянскому шаблону
- Генерирует PDF для печати (без Microsoft Office)

## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python main.py          # GUI
python main.py --test   # автотест
```

## Структура

```
├── main.py             # точка входа
├── calc.py             # расчётный модуль (формулы, таблица W)
├── excel_export.py     # экспорт Excel (патчинг шаблона через lxml)
├── pdf_export.py       # генерация PDF (PyMuPDF overlay)
├── gui.py              # Tkinter интерфейс
├── requirements.txt
└── assets/
    ├── template.xlsx           # оригинальный шаблон протокола
    ├── report_background.pdf   # бланк для PDF
    ├── demo_signature.png      # демо-подпись (ОБРАЗЕЦ)
    └── demo_stamp.png          # демо-печать (ОБРАЗЕЦ)
```
